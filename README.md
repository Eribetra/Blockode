# Blockode
A Scratch 1.4 mod.
<br>
Currently using Squeak 3.10.10, but support for 5.0 is in development.

hacame cambios
"¡Hola! Me encanta el enfoque de Blockode para conectar los bloques con el código de texto. ¿Has considerado alguna vez migrar o recrear el proyecto como un mod basado en Scratch 3.0? Con la arquitectura moderna de HTML5/JavaScript y herramientas como los componentes de TurboWarp o PenguinMod, el editor sería mucho más accesible para los estudiantes de hoy en día, ya que funcionaría en la web y dispositivos móviles sin necesidad de instalar entornos antiguos. ¡Sería un cambio increíble para el proyecto!"
